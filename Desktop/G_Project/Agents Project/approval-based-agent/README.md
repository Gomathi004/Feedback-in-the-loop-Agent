# Approval-Based Agent

## About the Project

The Approval-Based Agent is a simple Python project that asks for user approval before creating a file. It prepares content based on the user's task and displays the proposed action.

The file is created only when the user approves the action. If the user rejects it, the file will not be created.

## Features

- Accepts tasks from the user.
- Generates predefined content based on keywords.
- Displays the proposed action before execution.
- Creates a file only after user approval.
- Cancels the action if the user rejects it.
- Prevents overwriting existing files.

## Technologies Used

- Python
- Python Standard Library

## How It Works

1. Enter a task.
2. The agent prepares content.
3. Review the proposed action.
4. Type `yes` to approve or `no` to reject.
5. The file is created only after approval.

## How to Run

**Step 1:** Clone the repository.

```bash
git clone https://github.com/Gomathi004/Approval-Based-AI-Agent.git
```

**Step 2:** Open the project folder.

```bash
cd Approval-Based-AI-Agent
```

**Step 3:** Run the Python program.

```bash
python main.py
```

No additional package installation or API key is required for the Python-only version.

## Purpose

This project demonstrates a basic human-approval workflow in which an action is reviewed before execution.
